## Реалізовано

- Спрощена Create-форма: URL, формат Shorts/Longs, стиль, Generate; автоматична
  перевірка джерела, додаткові параметри в Advanced Settings, збереження вподобань.
  Текст озвучення, URL, часовий діапазон і дозвіл автопублікації не переносяться
  автоматично між джерелами. Права на матеріали підтверджуються для кожного завдання.
- Оригінальний звук за замовчуванням; окремі режими Silent, музика з ducking/fade,
  необов'язкове локальне озвучення Kokoro EN/ES та реальні голосові прев'ю.
- Багатогодинний аналіз через аудіочанки до 15 хвилин з контрольними точками.
  Повне віддалене VOD не завантажується як прихований fallback.
- Валідований відбір Ollama, пояснення непридатного/візуального матеріалу,
  явний heuristic fallback для технічних збоїв та порожніх некоректних відповідей.
- Реальні FFmpeg Crop/Blur/Gameplay Split, CPU-виявлення облич для Smart Crop,
  згладжування камери та Blur fallback без облич, субтитри, hooks, видалення пауз
  зі спільною шкалою часу для відео, аудіо та слів. Longs монтуються хронологічно.
- Збережені етапи й виміряні лічильники. Завершені файли Drive рахуються після
  перевірки, а не за умовним таймером. Архівні завдання позначають відсутність
  старої деталізації. Health перевіряє, що локальний воркер живий.
- Виправлено падіння воркера після першого завдання та абсолютний шлях FFmpeg
  для yt-dlp. Retry фіксує відбір у analysis.json і перевіряє кешовані уривки,
  щоб не поєднати старий MP4 із новими часовими межами.
- Повторно використано чинний split-file Drive OAuth; початкові файли незмінні.
  Upload перевіряє розмір і MD5. Вихідні вибрані уривки зберігаються в Drive:
  Editor створює нові версії після локального очищення. Повне джерело не архівується.
- Збережено реалізацію прямого resumable Drive→YouTube, review/private defaults,
  політик каналів, scheduling, session reconciliation та захисту від дублікатів.
  Реального YouTube upload не було: користувач дозволив продовжити без нього.
- Оновлено Docker, опційний GPU/TTS build, CI саме для factory-коду, README,
  інструкції PC A/PC B, provenance і ліцензійні пояснення. Runtime не включає cloud/.

corrupted output, resumable publisher retry використовують контрольовані fixtures.
Вони не підтверджують реальний YouTube upload.

  синтетичним фоном; справжній авторизований gameplay-пакет не перевірено.

## Ресурси та поточний стан

Фактичне середовище: Windows 11, Python 3.12, Docker Desktop Linux/WSL2,
RTX 3050 **6 GB**, 15,2 GB доступної системі RAM. Під час короткого LLM-тесту
спостерігалось: controller ~542 MiB RAM, Ollama ~2,693 GiB, web ~17 MiB;
Ollama показувала 39% CPU / 61% GPU offload, GPU memory used snapshot 1841 MiB.
Це окремі вимірювання, не максимальні значення навантаження. Пікові метрики довгого
тесту не збережені через переривання. Scratch має 8 GiB budget / 4 GiB free reserve.

**За проханням користувача Docker Desktop, WSL і тестові процеси зупинені.**
Остання перевірка запущеного controller/web/ollama перед зупинкою була healthy.
Передача комітів не запускає ці служби повторно.

## Запуск після передачі

PC A: `docker compose --profile controller up -d --build`

PC B після одноразової конфігурації приватного CONTROLLER_URL, токена і чинного
Drive mount: `docker compose --profile worker up -d --build`.

UI: http://localhost:5175 . Докладні GPU/TTS-команди, авторизація та відновлення:
`docs/FACTORY_DEPLOYMENT.md`. Секрети, session URL, ваги моделей і згенеровані
відео/аудіо не включаються в нові коміти. Історія репозиторію збережена.
